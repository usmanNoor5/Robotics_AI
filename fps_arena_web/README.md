# FPS Arena (Web)

A small 3D first-person shooter you can run in the browser using `three.js` (CDN).

## Controls

- `Arrow Keys`: move
- `Mouse`: look (click canvas to enable pointer lock)
- `Space`: shoot

You fight 1 computer-controlled enemy in a simple arena with a central pillar obstacle.

## Run locally

From this folder:

```bash
python3 -m http.server 5173
```

Then open:

`http://localhost:5173/`
