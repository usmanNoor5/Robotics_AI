# Kanban

Single-board Kanban MVP built with Next.js in [`frontend`](./frontend).

## Stack

- Next.js 16.2.1
- React 19.2.4
- `@hello-pangea/dnd` for drag and drop
- Vitest for unit tests
- Playwright for end-to-end tests

## Run

```bash
cd frontend
npm install
npm run dev
```

Use Node `22.22.2` or newer.

## Test

```bash
cd frontend
npm run lint
npm run test:unit
npm run test:e2e
```
